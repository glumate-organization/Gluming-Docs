# AI 랜딩 문법 줄이기

목적: 글루밍 사이트에서 "AI가 만든 듯한 흔한 랜딩 문법"을 찾아 줄이고, 브랜드·실제 제품 화면·구체 정보가 먼저 보이게 한다.

쓰는 때: 랜딩/하위 페이지 디자인 검토, "AI스럽다·템플릿 같다" 피드백, 리디자인 전 점검.
안 쓰는 때: 카피만 고칠 때(→ `wellness-content`), 자산 처리(→ `self-contained-assets`), 새 섹션 설계(→ `landing-page`).

## 작업 규칙

- 점검표를 먼저 보여주고, 정훈님 승인을 받은 항목만 코드로 고친다 (CLAUDE.md 변경 워크플로우).
- 범위는 발견된 항목으로 한정한다. 표에 없는 부분은 손대지 않고, 전체 리디자인으로 넓히지 않는다.
- 점검표에는 실제로 나타난 항목만 적는다. "해당 없음" 항목은 나열하지 않는다.
- 라우트·링크·데이터·기존 컴포넌트 props·SEO 메타(JSON-LD, sitemap)·자가완결 원칙은 그대로 유지한다.
- 후기·수치·파트너·수상·사업자 정보·데이터 처리 방식은 지어내지 않는다. 필요하면 `<!-- TODO: 입력 필요 -->`로 표시한다.
- 색·반경·그림자·간격·타이포는 `src/styles/global.css` 변수(`--primary`, `--r-*`, `--shadow-*`, `--sp-*`, `--fs-*`)만 쓰고 새 하드코딩 값은 넣지 않는다.
- 새 패키지·외부 스크립트·외부 폰트는 추가하지 않는다.

## 절차

1. 읽기: 대상 페이지(`src/pages/*.astro`) + 공용(`src/layouts/Layout.astro`, `src/components/*`, `src/styles/global.css`)을 실제로 연다. 화면 캡처가 있으면 함께 본다.
2. 점검표 작성: 아래 20개 중 실제로 나타난 것만 [점검표 템플릿]으로 정리한다. 각 항목에 근거 위치(`파일:줄`)를 적는다.
3. 승인 대기 → 승인된 항목만 수정. 한 항목 = 한 수정 단위로 작게.
4. 검증: [검증] 절 명령 실행 + 데스크톱/모바일(≤390px) 레이아웃, 버튼, 링크, 키보드 포커스, 대비 확인.
5. 보고: [완료 보고 템플릿]으로 마무리.

## 20가지 패턴 — 찾는 단서와 대체

| # | 패턴 | 코드에서 찾는 단서 | 대체 | 글루밍 메모 |
|---|---|---|---|---|

| 2 | 의도 없는 흰색 전면 배경 | `background:#fff` 전체, 섹션 리듬 없음 | `--bg`(warm paper)·`--warm`·`--pine` 면으로 섹션 리듬 | 기본 배경은 이미 `--bg` |
| 3 | 모든 설명에 반복되는 선형 아이콘 | 카드마다 동일 크기 stroke 아이콘 `<svg>` | 아이콘 제거, 구체적 제목·설명·제품 화면으로 대체 | 장식 벡터는 `Sprout.astro` 만 |

| 5 | 제품 톤과 안 맞는 이모지 | 마크업/카피 안 이모지 문자 | 제거 | `brand.md` §2 이미 금지 |

## 대체 디자인 원칙 (판단 기준)

- 색: 브랜드 주색 1 + 중립 + 강조 1 안에서 먼저 해결.
- 모서리·그림자·여백: 소수의 토큰으로 통일하되, 역할별로 차이를 둔다. 전부 똑같이 만들지 않는다.
- 첫 화면: 실제 제품 화면 / 입력→결과 / 사용 장면 중 하나가 보이게 한다.
- 아이콘·장식: 의미가 있을 때만. 구체적 제목·설명이 대신할 수 있으면 제거.
- 섹션·카드 수: 내용에 맞춘다. 3개씩 억지로 맞추지 않는다.
- 폰트: 브랜드 성격·한글 가독성 기준. 크기·굵기·행간으로 위계.
- 애니메이션: 제품 이해를 도울 때만. `prefers-reduced-motion: reduce` 대응(`global.css:379` 패턴 재사용).
- 카피를 바꾸면 `wellness-content` 스킬(의료/단정 표현 금지)을 따른다.

```bash

grep -rnE "https?://[^\"' )]+\.(png|jpg|svg|woff2?)" src   # 외부 자산 0건이어야 함
grep -rnE "#[0-9a-fA-F]{3,8}\b" src/pages src/components  # 하드코딩 색. 기준선 3건(#ffffff) 보다 늘면 안 됨
```
